# 复扫雷 ComplexSweeper v1.0.0

这是三个原生移植工程合并后的首个 Release。原作由[青月晓](https://github.com/Yueqing-Chen/complexweeper-A-minesweeper-game)开发，本移植基于 Windows 原作 v1.2.0，由 Ray Chen（Rayawa）维护。

## 功能与改进

- HarmonyOS、Android、iOS / iPadOS / macOS 共用圆复数规则、四种雷、24 个显示值和标准三档难度。
- 保留首击九宫格安全、空白连片展开、旗子保护、展开判据、胜负复盘、四计雷器、最快纪录、原作像素素材及六段音效。
- 修复首击与胜负边界、iOS 计雷器刷新和轻点 / 长按冲突；三端统一单调时钟与提示取消逻辑。
- 安卓保留 Activity 旋转前的局面；Apple 与安卓重开恢复棋盘滚动位置。
- 三端应用图标主体比例统一；安卓使用矢量自适应图标，修复小尺寸图标采样；Apple 应用名称统一为「复扫雷」。
- 三端原作者署名链接原仓库；仓库总 README 和各平台技术文档已按合并后的结构整理。

当前未移植双曲复数模式、自定义雷区 / 指定雷型配比、音效开关及独立纪录窗口。应用内版本号为 `1.0`，Release 标签为 `v1.0.0`。

## 附件与安装

| 文件 | 平台 / 用途 | 签名与安装说明 |
| --- | --- | --- |
| `ComplexSweeper-v1.0.0-android.apk` | Android 12+，Release APK | 使用开发测试证书签名，可直接安装；不是商店发布证书 |
| `ComplexSweeper-v1.0.0-android-unsigned.apk` | Android Release APK | 未签名，供自行签名 |
| `ComplexSweeper-v1.0.0-android-unsigned.aab` | Android App Bundle | 未签名，供后续签名 / 发布处理 |
| `ComplexSweeper-v1.0.0-harmonyos-unsigned.hap` | HarmonyOS，兼容 API 23+ | 未签名，需使用自己的 HarmonyOS 证书与描述文件签名后安装 |
| `ComplexSweeper-v1.0.0-macos.zip` | macOS 14+，arm64 / x86_64 | 解压为 `复扫雷.app`；未配置 Developer ID 发布签名、未公证 |
| `ComplexSweeper-v1.0.0-ios-simulator.zip` | iOS / iPadOS 17+ 模拟器，arm64 / x86_64 | 解压为 `复扫雷.app`，仅供模拟器 |
| `ComplexSweeper-v1.0.0-ios-device-unsigned.zip` | iOS / iPadOS 17+ 真机 App，arm64 | 未签名，开发者需自行签名与配置描述文件；不能直接当 IPA 安装 |
| `SHA256SUMS.txt` / `manifest.json` | 附件校验与构建信息 | 含文件大小、哈希、源码提交和验证结果 |

本次不公开本机开发证书、密钥或仅限指定设备的 iOS / HarmonyOS 开发描述文件。需要通用真机安装的 Apple / HarmonyOS 分发包时，须配置相应发布签名。
Android APK 后续若换用不同签名证书，更新前需要卸载原测试签名版本。

下载后可用 `shasum -a 256 -c SHA256SUMS.txt` 校验附件；Linux 也可使用 `sha256sum -c SHA256SUMS.txt`。
