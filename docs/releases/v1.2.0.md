# 复扫雷 ComplexSweeper v1.2.0

三端同步上游 `f6b80bb35690ad4498e2e0179353bc8b369a2d70` 的彩色与专用黑白图集，并改进触屏翻开操作。
原作由[青月晓](https://github.com/Yueqing-Chen/complexweeper-A-minesweeper-game)开发，原生移植由 Ray Chen（Rayawa）维护。上游源码版本1.3.0与移植应用版本1.2.0各自维护。

## 更新

- 新增「彩色｜黑白」原生分段选择器，默认彩色，重启恢复外观偏好。HarmonyOS位于系统顶栏中央，Android位于标题栏，Apple与难度选择并排位于棋盘上方。
- 两种玩法的数字、旗帜、雷、结算标记、人脸与计数器使用上游专门绘制的黑白图案；同步彩色图集细节及图标。
- 外观切换及重复选择保留当前局面、旗帜与计时，兼容既有战绩。
- 长按带标记格会自动清除该格标记并翻开，计雷器即时更新。首击仍保证目标及八邻域安全；已开局时翻到雷正常判负。macOS左键同步采用该规则。
- 空白连片展开和数字格展开仍跳过其他带标记格。
- 新增三端素材一致性CI检查，补充长按清旗、外观持久化、顶栏位置及iPhone / iPad横竖屏回归，更新教程和工程文档。

应用版本统一为1.2.0；Android versionCode与Apple build为3，HarmonyOS versionCode为1002000。
自定义雷区、指定四雷配比、音效开关及独立纪录窗口仍属后续移植范围。

## 验证

- 三端引擎通过各360局圆复数与360局双曲回归、39个双曲显示值、178,200次展开判据及固定种子检查。新增两种模式×四类标记的首击、安全格、踩雷、计数恢复和其他标记保留检查通过。
- 三端两套共232张图集切片的SHA-256、尺寸、非空和黑白灰度检查通过。
- Android 15项JVM测试通过，发布前lint零错误，Release APK / AAB构建通过；设备交互测试APK编译通过，尚未连接Android设备执行。
- iPhone 18 Pro模拟器10项独立交互用例通过，其中计雷器1项修正测试中负数显示的符号预期后单独补验通过；覆盖外观、持久化、横竖屏及长按清旗。
- iPad Pro 11英寸M4真机外观与布局完整10项通过；后续长按清旗及计雷器更新2项定向真机测试通过，均为无线连接。
- HarmonyOS PLA-AL10真机最新完整7项Hypium / UiTest通过，0失败、0错误；包括两种模式四类标记的长按翻开、其他标记保留、外观切换与顶栏布局。
- iPhone17已覆盖安装最终开发签名应用；外观与横屏曾通过官方Device Hub交互验收，后续长按清旗规则尚未确认该设备的触摸验收。无线XCUITest初始化失败，不计作真机自动化通过。
