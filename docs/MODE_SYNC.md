# 复扫雷三端新增模式同步 · 1.1.0

日期：2026-10-12。
原版基准：`Yueqing-Chen/complexweeper-A-minesweeper-game`，远端最新提交 `80502e5e8b222362cbe86d57588f2c0fbbb11a3f`，应用版本 v1.2.0。
已更新本仓库内 HarmonyOS、Android、Apple Platform 三个工程。三端应用版本统一为 1.1.0。

## 本次更新

- 加入闵可夫斯基（双曲复数）模式：j²=+1，四种雷为 +1、−1、+j、−j。实部对应类空部，j 部对应类时部。
- 整数显示值为 D=a²−b²，完整覆盖39个可达值；D<0显示 √|D|i，例如 −4 显示2i。真实雷格使用 `mineKind` 区分，负显示值不会被误当作雷。
- 默认展开判据按原版源码：旗数等于真雷数，旗帜净和与真雷净和的 |a|、|b| 分别相等，允许各自取反。圆复数原有展开判据保留。
- 只有周围完全无雷的空白格自动扩散；双曲模式中的非空白零值（包括 +1/+j 形成的零）不自动扩散。
- 底部 Tabs 切换圆复数／闵可夫斯基；初级／中级／高级使用独立分段选择。macOS 难度保留在窗口工具栏。
- 切换模式保留难度并重开，切换难度保留模式并重开；重复选择当前项保留局面，点人脸重开也保留模式。
- 两种模式分别保存三档最快纪录与胜负场次，圆复数沿用旧存档键，无需迁移。
- 同步116个上游图集槽位，补齐 j 雷／旗、爆炸、结算与负显示值素材，更新计雷器单位、无障碍描述和教程。
