# 复扫雷 ComplexSweeper v1.1.0

三端同步 Windows 原作 v1.2.0 的新增模式，基准提交 `80502e5e8b222362cbe86d57588f2c0fbbb11a3f`。
原作由[青月晓](https://github.com/Yueqing-Chen/complexweeper-A-minesweeper-game)开发，原生移植由 Ray Chen（Rayawa）维护。

## 新增与修正

- HarmonyOS、Android、iOS / iPadOS / macOS 新增闵可夫斯基（双曲复数）模式：j²=+1，四种雷为 ±1、±j，支持 39 个显示值与负值 √|D|i。
- 按原作源码默认严格判据展开数字格：旗数匹配，实部与 j 部的净和绝对值分别匹配；真正无雷的空白格才会自动连片展开。
- 底部 Tabs 改为模式切换，难度独立选择。Android 使用 Material 3 分段按钮，iOS / iPadOS 使用分段 Picker，HarmonyOS 使用参照 Dashboard 的系统 TabSegmentButtonV2；macOS 难度位于工具栏。
- 切换模式保留难度，切换难度保留模式，重复选择保留当前局；两种模式分开保存三档战绩，保留圆复数原有记录。
- 补齐 j 雷 / 旗、爆炸、结算、LED 单位及双曲数字，三端对齐全部 116 个原作图集槽位，更新教程与无障碍描述。
- Apple 标题在系统深浅色下均为黑色；macOS 状态提示改用左右键措辞。
- 修正 HarmonyOS「关于」右上角关闭叉号错位和底部原作署名未居中的问题。
- 根 README 与三端 README 统一更新为当前功能、构建方法和验证结果。

应用版本统一为 `1.1.0`；Android versionCode 为 2，Apple build 为 2，HarmonyOS versionCode 为 1001000。
自定义雷区、指定四雷配比、音效开关及独立纪录窗口仍未移植。

## 验证

- 三端引擎各通过 360 局圆复数与 360 局双曲复数回归、39 个双曲显示值覆盖和 178,200 次展开判据检查；两种模式固定种子指纹对齐。
- 三端全部 116 张图集 PNG 的 SHA-256 一致；Apple 旧存档兼容和模式战绩隔离检查通过。
- Android 15 项 JVM 单测通过，lint 零错误；Debug 应用、设备测试 APK 及 Release APK / AAB 构建通过。5 项设备交互测试已编译，尚未连接 Android 设备执行。
- iPhone 18 Pro / iOS 27 模拟器上 8 项 XCUITest 通过；iPhone 17 / iOS 27.2 经官方 Device Hub 完成实际交互和深浅色标题验收。无线真机 XCUITest 运行器连接未成功，8 项自动化结果来自模拟器。
- macOS 本机鼠标操作、模式 / 难度、负显示值、教程与标题验收通过。
- 华为 Mate 70 Pro+ 上 5 项 Hypium / UiTest 全部通过（0 失败、0 错误），包括原生难度分段控件和「关于」布局回归。
- 所有发布附件重新以 Release 配置构建，完成版本、架构、ZIP 完整性和 Android 签名校验。
